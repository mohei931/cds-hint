# CDS-Hint · 临床辅助诊断提示原型

面向「临床诊疗与文书」场景的小型开源原型：把**主诉 + 症状 + 生命体征**转成结构化提示 —— 先做红旗征（red flag）筛查，再给出鉴别诊断思路排序、建议检查清单和需要继续采集的信息。

> ⚠️ **仅供技术演示与流程验证**：本项目输出不是诊断结论，不构成处方或治疗方案，不能替代医师判断；不属于医疗器械，不可直接用于真实患者诊疗。详见 [免责声明](#免责声明与合规边界)。

## 它解决什么

临床上真正难的不是"想到某个病"，而是三件事：

1. **别漏掉危重** —— 胸痛要先排 ACS、主动脉夹层、肺栓塞、气胸；
2. **思路要成体系** —— 按证据强弱排出鉴别顺序，而不是罗列一堆病名；
3. **还缺什么** —— 明确告诉医生下一步该问什么、该查什么。

本原型用**可解释的规则化知识库**做这三件事，输出每一项判断都带证据来源（命中了哪条线索、哪条生命体征），便于医生快速核对而不是盲信模型。

## 当前覆盖的临床情景

| 情景 | 鉴别诊断条目 | 红旗征规则 |
| --- | --- | --- |
| 急性胸痛 | 7（ACS、肺栓塞、气胸、反流、胸壁痛、肺炎等） | 4（ACS、夹层、肺栓塞、气胸） |
| 急性腹痛 | 8（阑尾炎、胆囊炎、胰腺炎、溃疡、结石、妇科急腹症、肠梗阻、腹膜炎） | 5（穿孔、出血、肠系膜缺血、异位妊娠、胰腺炎） |
| 头痛 | 5（偏头痛、紧张型、丛集性、药物过量、继发性头痛） | 4（SAH、颅内感染、占位/颅高压、高血压相关） |
| 发热 | 4（呼吸道、泌尿系、病毒感染、胆道感染） | 2（脓毒症、中枢感染） |
| 呼吸困难 | 4（慢阻肺/哮喘、心衰、肺炎、贫血） | 3（呼吸衰竭、急性心衰、肺栓塞/气胸） |

## 推理机制（可解释，无黑盒）

1. **情景路由**：把主诉、症状、既往史拼成规范化文本（全角转半角、去标点、小写），按 `entry_terms` 权重选出命中的临床情景。
2. **红旗征优先**：红旗规则由症状词 + 生命体征阈值组成，可用 `min_hits` 要求多条线索同时成立，降低单一非特异线索的误报。
3. **鉴别打分**：每条鉴别有 `support`（支持线索及权重）、`against`（反向线索）与 `modifiers`（年龄/性别风险因素），得分 = 支持权重 − 反向权重，按分排序；标 `critical` 的危重鉴别在红旗命中时强制进入前列，避免漏项。
4. **输出建议**：红旗征给出"立即/尽快"的处置动作与检查；检查清单按相关度合并为「优先完成 / 按需完善」；问诊问题只从相关度足够的鉴别里生成。

知识库按情景拆分成独立文件，位于 [`knowledge/presentations/`](knowledge/presentations/)（每个病种一个 JSON），加一个情景只需新增一个文件，无需改代码。

### 可选 LLM 解释层

默认关闭。规则引擎负责"算"，LLM 只负责"讲"，且提示词里禁止新增诊断、禁止给剂量和治疗方案：

```bash
export CDS_LLM_BASE_URL=https://your-endpoint/v1
export CDS_LLM_MODEL=your-model
export CDS_LLM_API_KEY=sk-xxx
```

调用失败会静默降级为规则模板，不影响主流程（见 `app/llm.py`）。

## 局限（务必先读）

- 知识库为**演示级**内容，条目少、权重靠人工设定，**未经临床验证**，没有任何诊断性能指标。
- 中文按**子串匹配**，未做同义词全量归一与否定识别（"无胸痛"会被当成"胸痛"），这是当前最大的技术短板。
- 不做分诊分级、不给用药建议、不输出概率，`match_level` 只是证据强弱描述，不是患病概率。
- 不处理真实患者数据；示例病例均为构造数据。

## 免责声明与合规边界

本项目是**技术原型**，不构成任何医疗建议，不可作为医疗器械使用。若要在院内真实环境落地，至少需要：

1. **资质与注册**：涉及诊断辅助功能的软件按《医疗器械监督管理条例》通常属二类/三类医疗器械，需完成注册或走临床决策支持类软件的合规路径；生成式 AI 还须遵守相关生成式人工智能服务管理规定。
2. **数据合规**：遵循《个人信息保护法》《数据安全法》，患者数据脱敏、最小必要、本地化处理，不得把可识别信息送入外部模型。
3. **医师闭环**：所有提示必须可追溯到证据，且由医师确认后才能进入病历；系统只做"提示"，不做"结论"。
4. **可审计**：保留输入、命中规则、输出与医师采纳/驳回记录的完整日志。
5. **性能验证**：上线前需在真实数据上做回顾性与前瞻性评估（漏诊率、过度检查率、医师采纳率），并持续监测漂移。
